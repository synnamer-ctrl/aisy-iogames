# Free sprite packs (CC0)

Sprite packs by [Kenney](https://kenney.nl), released under **CC0 1.0** (public domain):
free for any use, commercial included, no credit required. Each folder keeps its original `License.txt`.

These are a library to pick from; the game doesn't load them yet, and the service worker doesn't cache them.
Open `preview.png` in each folder to see everything at a glance.

| Folder | What's inside | Sprites |
|---|---|---|
| `animal-pack/` | Round and square animal faces (elephant, giraffe, hippo, monkey, panda, parrot, penguin, pig, rabbit, snake), with and without outlines | 80 |
| `background-elements/` | Clouds, trees, bushes, cacti, houses, castles, fences, hills, sun and moon | 110 |
| `jumper-pack/` | Bright platformer bits: bunny player, clouds, platforms, springs, coins, stars, power-ups, enemies, HUD | 121 |
| `shape-characters/` | Shapes with faces in many colours (circles, squares, triangles, stars…) plus separate faces | 208 |
| `particle-pack/` | Transparent effects: stars, sparkles, smoke, flames, glows, magic | 80 |

Source pages: kenney.nl/assets/animal-pack, /background-elements, /jumper-pack, /shape-characters, /particle-pack.
